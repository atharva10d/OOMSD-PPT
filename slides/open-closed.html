"Add new behavior without editing existing, tested code."

The Problem It Solves

Discount rules never stop growing.

Today

Standard pricing and infant discounts.

Tomorrow

Airline introduces Frequent Flyer Miles, Corporate Discounts, or Holiday Promos.

Editing a massive if/else block inside the price calculator risks introducing bugs into standard fare calculations.

Airline Solution

Plug in new strategies. Never touch the engine.

interface IPricingStrategy

.calculateTotal()

class FreqFlyerPricing

.calculateTotal()

class CorporatePricing

.calculateTotal()

A new promotional strategy is just added as a new class. The core booking engine code is never touched.
