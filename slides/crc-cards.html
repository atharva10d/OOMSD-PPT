MODELLING CONCEPT

CRC Cards

"Class — Responsibility — Collaborator": a quick, low-tech way to discover classes before drawing formal UML.

What It Is

An index-card style technique used early in design to brainstorm what a class knows/does and which other classes it needs.

The 3 Components

Class

The object or entity.

Responsibility

What the class knows or does.

Collaborator

Other classes it interacts with.
