System Architecture Diagram

A four-layer separation keeps presentation, business logic, third-party integration and persistence independently replaceable.

Layer 1

User Interface
(UI) Layer

Passenger Portal — search, book, check-in
Agent Dashboard — manage multiple client bookings
Admin Panel — inventory, crew and reports

Layer 2

Core Booking Engine
(Business Logic)

Flight Search & Routing Service
Dynamic Seat Allocation Manager
Pricing & Refund Calculator

Layer 3

External
Integration Layer

Payment Gateway Service
Email / SMS Notification Service

Layer 4

Data Storage
Layer

Flight Inventory DB
User & Authentication DB
Transaction & Reservation Logs

Design Payoff

Any layer can be swapped without recompiling the layers above it.
