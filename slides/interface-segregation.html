Principle 04 · I

I — Small, Role-Specific Interfaces

"Clients should not be forced to depend on methods they don't use."

Bad Design — Before

The fat interface

BASE INTERFACE

interface IAirlineSystem

+bookSeat()
+cancelTicket()
+addFlightRoute()   ⚠️
+removeCrewMember()

Consequence

A Passenger is forced to implement addFlightRoute() — a method they have zero permission to use.

Airline Design — After

Split by role, not by system

interface IBookable

implemented by
Passenger, TravelAgent

+ bookSeat() + cancelTicket()

interface IInventoryManager

implemented by
Admin

+ addFlightRoute() + updateSchedule()

Actors implement only the interfaces they actually need — keeping the system secure and lean.
